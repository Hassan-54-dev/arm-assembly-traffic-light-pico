# Bare-Metal Traffic Light Controller in ARM Assembly (Raspberry Pi Pico)

Engineered a bare-metal Traffic Light System for the Raspberry Pi Pico (RP2040) utilizing ARM Assembly (Cortex-M0+), developed in VS Code and tested via the Wokwi Simulator.

## 🚀 Project Overview
This project communicates directly with the processor registers to handle low-level GPIO control, timing delays, and sequential state transitions for an automated traffic light intersection model.

## 🛠️ Key Features
- **Bare-Metal Development:** Written entirely in low-level ARM Assembly (Cortex-M0+) without heavy abstraction layers.
- **Efficient Register Usage:** Optimized register allocation and direct memory-mapped I/O configuration.
- **Simulation & Testing:** Developed inside VS Code and fully validated using the Wokwi online simulator.
